# 日経新聞 × Singerly見解 SNS投稿プロンプト

## 概要

日経新聞の一面情報を元に、Singleryとしての見解を加えたSNS投稿案（X投稿用）と
パワポスライド（1枚・SNS共有用）を生成するプロンプト。

**出力の3点セット：**
1. 著作権に配慮したニュース要点（自分の言葉で再解釈済み）
2. X投稿案（140文字版 ＋ ロング版）
3. パワポスライド（python-pptxで自動生成 → `.pptx` で保存）

---

## インプット準備（実行前に必ず確認）

ユーザーは以下の情報をチャットに貼り付けて実行する：

```
【今日の日経一面メモ】
日付: YYYY年MM月DD日
見出し: （一面のメインタイトルをメモ）
概要: （内容を自分の言葉で100字程度にまとめたもの）
注目数字: （記事に出てきた印象的な数字や統計）
```

---

## 著作権ガイドライン（必読・必須適用）

日経新聞の記事は著作権保護対象です。以下のルールを厳守する。

### やること
- 記事の「ファクト」（数字・日付・固有名詞）は引用可能（事実は著作権保護対象外）
- 見出しを短く言及することは許容範囲（判例上の慣行）
- Singerly独自の分析・見解を必ず追加する（変容的利用）
- 出典を明記：「参考：日経新聞 YYYY年MM月DD日朝刊」

### やらないこと
- 記事本文を100文字以上そのままコピーしない
- 記事の文体・表現をそのまま流用しない
- 「記事によると〜という内容です」で終わる投稿は作らない（分析・見解なしは不可）
- 有料記事への誘導URLは貼らない（読者のフラストレーションを避ける）

### 判断基準
> 「日経の記事を読んでいない人が読んでも価値ある投稿か？」
> → Yes なら著作権面・コンテンツ面ともにOK

## STEP 1: ニュース整理（著作権対応版）

ユーザーから受け取った情報を元に、以下の構造で整理する。

```
【ニュース核心】（日経の内容を自分の言葉で再解釈）
・ポイント1: ファクトを短く（〜20字）
・ポイント2: ファクトを短く（〜20字）
・ポイント3: 背景・文脈を短く（〜20字）
出典: 参考：日経新聞 YYYY年MM月DD日朝刊一面
```

**整理のルール：**
- 記事の文章をそのまま使わず、自分の言葉に変換する
- 数字はそのまま使用可（例：「採用コスト平均80万円」）
- 社名・固有名詞はそのまま使用可

---

## STEP 2: Singerly見解の付加

整理したニュースに対して、以下の観点でSingerly（奥田真広）としての見解を3点生成する。

### 奥田真広について
- CEO of Singerly / コンセプト「はたらいて泣こう」
- エンゲージメント2倍・採用効率20倍の組織づくりが専門
- X: @SingerlyCEO / note: note.com/singerly

### 見解の切り口（このニュースが組織・採用・エンゲージメントとどう繋がるか）
- **組織文化への影響**: このニュースが職場の空気・文化にどう作用するか
- **マネジャー・経営者への示唆**: 何をどう変えるべきか
- **逆張りインサイト**: 多くの人が見落としているポイントは何か

### 奥田の文体ルール（見解にも適用）
- 短い断言を多用：「制度より空気。これが全て。」
- 括弧内のツッコミを1〜2回：（きついw）（超大事）（それメッチャむずいわね！）
- 突然テンションが上がる例え（ビジネス外から）：インディーズバンド・職人・スポーツ選手
- 「〜だったら、どうなるか」で読者の想像力を刺激
- 丁寧語3文以上続けない・まとめ表現禁止

---

## STEP 3: SNS投稿案生成

### ① X投稿案（140文字版）
- 全角日本語で正確に140文字以内
- 冒頭はファクト（数字・意外性）で始める
- 末尾：「参考：日経新聞 MM/DD」
- 絵文字なし

### ② X投稿案（ロング版・280文字程度）
- 冒頭：断言 or 問いかけ
- 中盤：ニュースファクト＋Singerly見解
- 末尾：読者への問い返し or 「詳しくはnoteで→ note.com/singerly」
- 絵文字なし

### ③ スライド用キャプション（投稿時に画像と一緒に使う短文）
- 15文字以内
- サムネイル的なインパクト重視
- 例：「採用の常識を疑え」「組織崩壊の予兆」

---

## STEP 4: パワポスライド生成

以下のコマンドを実行してスライドを生成する：

```bash
python3 /Users/okudamasahiro/work/ops/nikkei_sns_slide.py \
  --date "YYYY年MM月DD日" \
  --headline "見出し（自分の言葉）" \
  --points "ポイント1|ポイント2|ポイント3" \
  --singerly "見解1|見解2|見解3"
```

生成後のファイルは `/Users/okudamasahiro/Desktop/nikkei_sns_YYYYMMDD_HHMMSS.pptx` に保存される。

**スライド構成（自動生成）:**
- 背景: ダークネイビー（#0E2841）
- 上部: オレンジ帯「今日の日経 × Singerly見解」
- 左列: 「今日のニュース」（日付・ポイント3点）
- 右列: 「Singerlyの視点」（見解3点）
- 下部フッター: 出典「参考：日経新聞 YYYY年MM月DD日朝刊」＋「Singerly / はたらいて泣こう」

## 実行例

**ユーザー入力例：**
```
【今日の日経一面メモ】
日付: 2026年4月13日
見出し: 新卒採用、内定辞退が過去最高水準に
概要: 2026年卒の内定辞退率が65%を超え、企業の採用計画に大きな影響。
      特に中堅企業（従業員300〜1000人）での辞退率上昇が顕著。
注目数字: 内定辞退率65%超・中堅企業で前年比+12pt
```

**Claude出力例（X投稿140文字版）：**
```
内定辞退率が65%超。特に中堅企業は前年比+12ptという数字が重い。
「採用できた」は「選ばれた」とは違う。
入社意欲は内定後の体験で変わる。制度より、会いたい人がいるかどうか。
参考：日経新聞 4/13
```
