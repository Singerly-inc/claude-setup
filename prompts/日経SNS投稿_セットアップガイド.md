# 日経新聞 × Singerly SNS投稿 セットアップガイド（メンバー向け）

---

## このツールでできること

日経新聞の一面を見てメモするだけで、以下が自動生成されます：

1. **Singerly見解入りSNS投稿案**（X用 140文字 ＋ ロング版）
2. **SNS共有用パワポスライド**（1枚・ビジュアル入り）

著作権配慮・出典表記・独自見解の付加は Claude が自動で行います。

---

## 事前準備

### 1. Claude Code のインストール

```bash
npm install -g @anthropic-ai/claude-code
```

または https://claude.ai/code からダウンロード。

### 2. python-pptx のインストール（スライド生成に必要）

```bash
pip install python-pptx
```

### 3. プロンプトファイルの確認

以下のファイルが手元にあることを確認：

| ファイル | 用途 |
|--------|------|
| `日経SNS投稿_プロンプト.md` | 実行プロンプト本体 |
| `nikkei_sns_slide.py` | スライド生成スクリプト |

ファイルの入手先：Singleryの共有フォルダ、または奥田さんから直接共有

## 毎日の使い方（ステップバイステップ）

### Step 1: 日経新聞の一面をメモする

朝、日経新聞の一面（紙面 or アプリ）を見て、以下をメモする。

**ポイント：記事をそのままコピーしない。自分の言葉で書く。**

```
【今日の日経一面メモ】
日付: 2026年4月13日
見出し: （一面のメインタイトル ※自分の言葉でOK）
概要: （内容を自分の言葉で100字程度にまとめる）
注目数字: （記事に出てきた印象的な数字・統計）
```

**例：**
```
【今日の日経一面メモ】
日付: 2026年4月13日
見出し: 新卒内定辞退が過去最高水準に
概要: 2026年卒の内定辞退率が65%を超え、中堅企業（300〜1000人規模）での
      前年比上昇が特に顕著。採用活動のやり直しを余儀なくされる企業が増加。
注目数字: 辞退率65%超、中堅企業で前年比+12pt
```

### Step 2: Claude Code にプロンプトを読み込ませる

Claude Code を起動して、以下を貼り付けてEnter：

```
/Users/okudamasahiro/work/ops/claude-prompts/日経SNS投稿_プロンプト.md を読み込んで実行してください。

【今日の日経一面メモ】
日付: （メモした日付）
見出し: （メモした見出し）
概要: （メモした概要）
注目数字: （メモした数字）
```

### Step 3: 出力を確認・使う

Claude が以下を出力します：

**① X投稿案（140文字）**
→ そのままコピーしてXに投稿

**② X投稿案（ロング版）**
→ 画像と組み合わせて投稿。または加筆してnote投稿に発展

**③ スライド生成コマンド**
→ Claude が自動実行 → デスクトップに `.pptx` が生成される

**④ スライドを画像として保存**
→ PowerPointでスライドを開き「名前を付けて保存」→ PNG/JPEGで保存
→ Xに画像として添付して投稿

## スライドのデザイン仕様

生成されるスライドは以下のSingerly公式デザインで作られます：

| 要素 | 仕様 |
|-----|------|
| サイズ | 16:9ワイド（33cm × 18.6cm相当） |
| 背景 | ダークネイビー（#0E2841） |
| アクセント | オレンジ（#E97132） |
| 左列 | 今日のニュース（3ポイント） |
| 右列 | Singerlyの視点（3ポイント） |
| フッター | 出典 ＋「Singerly｜はたらいて泣こう」 |

---

## 著作権について（重要）

このワークフローは著作権を守るよう設計されています：

- 記事の文章はコピーしない（メモは自分の言葉で）
- 数字・ファクトは引用可能（著作権は表現を保護するがファクトは保護しない）
- Singerly独自の見解・分析を必ず付加する
- 出典を必ず明記する（スライドとXの両方に自動で入る）

**やってはいけないこと：**
- 有料記事の本文を100文字以上そのままコピーする
- 「日経に書いてありました」だけで終わる転載投稿
- 日経のオリジナル表現・文体をそのまま流用する

## よくある質問

**Q. 日経新聞を購読していないと使えない？**
A. 一面の見出しは新聞スタンドや駅でも確認できます。アプリの無料範囲で見出しだけ確認してもOK。

**Q. スライドのフォントが崩れる場合は？**
A. `python-pptx` のバージョンを確認してください。`pip install --upgrade python-pptx`

**Q. 毎日必ず投稿する必要がある？**
A. ワークフローのセットアップだけ共有しています。投稿頻度・タイミングは各自の判断で。

**Q. X以外のSNS（LinkedIn等）に使える？**
A. ロング版の投稿案はLinkedIn向けにも使えます。スライド画像もそのまま使用可能。

**Q. 生成した投稿案を編集してもいい？**
A. もちろん。あくまで下書きなので、自分の言葉で加筆・修正してください。

## コマンドリファレンス

### スライド単独生成（Claudeを通さず直接実行する場合）

```bash
python3 /Users/okudamasahiro/work/ops/nikkei_sns_slide.py \
  --date "2026年4月13日" \
  --headline "内定辞退率が過去最高水準に" \
  --points "辞退率65%超|中堅企業で前年比+12pt|採用計画に影響が拡大" \
  --singerly "採用できたは選ばれたとは違う|内定後の体験が入社意欲を決める|制度より会いたい人がいるかどうか"
```

オプション：
- `--output /path/to/output.pptx` で保存先を指定（省略時はデスクトップ）
